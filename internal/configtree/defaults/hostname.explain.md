# Device name (hostname)

This is the name the device uses to identify itself on your local
network — the name you'd look for in a list of devices, or type into a
web browser to reach it (for example `kitchen-clock.local`).

To set it, type a short name using only letters, numbers, and hyphens —
no spaces and no punctuation. For example:

    kitchen-clock

Whatever you type here becomes the name the device answers to, so
`kitchen-clock` above makes it reachable as `kitchen-clock.local`.

Leave this file empty to keep the name the device was built with. You
only need to set it if you want to tell two or more of these devices
apart on the same network, or you prefer a name of your own choosing.
