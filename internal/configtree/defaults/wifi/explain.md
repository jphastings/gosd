# WiFi network

This folder holds the details of the wireless network you want this
device to join: its name (`ssid`) and its password (`passphrase`).

If this device is connected with a network cable, or doesn't need any
networking at all, leave both files in this folder empty. The device
will simply not attempt to join a wireless network.

This device can join ordinary home and office wireless networks —
including ones with no password at all, and ones protected with the
common WPA2 password style. It cannot join the kind of WiFi network
that asks for a username as well as a password, such as those often
found at universities or large companies.
