# WiFi network name (ssid)

This is the name of the wireless network you want this device to join
— the same name you would pick from the WiFi list on your phone or
laptop.

Type it in exactly as it appears there, including capital letters. For
example, if your phone shows a network called:

    HomeNetwork5G

then type exactly that, with the same capital letters in the same
places.

Leave this file empty if this device isn't joining a wireless network.
See this folder's `explain.md` for more on that.
