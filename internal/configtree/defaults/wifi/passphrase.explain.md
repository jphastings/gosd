# WiFi password (passphrase)

This is the password for the wireless network named in the `ssid` file
next to this one.

Type the password in exactly as it was given to you, for example:

    correct-horse-battery

Capital letters and punctuation matter, so double check what you've
typed before saving.

Leave this file empty if the network has no password, or if this
device isn't joining a wireless network at all.
