# Save files promptly (data_flush)

This is an advanced setting, and most people can safely leave it empty.

Normally, this device writes files to the memory card a little while
after it decides to save them, so it can do other work in the meantime.
This setting tells it to push files to the card right away instead.

To turn it on, type any word into this file — for example:

    yes

Turning this on makes saving slightly slower, but there is less chance
that a very recent change is lost if power is cut unexpectedly. It is
not a guarantee against losing data — it only narrows the window in
which that can happen.

Leave this file empty for the normal, faster behaviour.
