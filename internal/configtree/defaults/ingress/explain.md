# Reaching this device from the internet

The folders inside this one let an app running on this device be
reached from the internet — for example, so you can open a web address
from anywhere and reach something running on this device at home.
This works without changing anything on your home router or setting
up port forwarding.

Which of these folders are present depends on how this device was
built — not every device offers every option. Open the `explain.md`
inside a folder to find out what that option needs from you and how to
fill it in.

If none of these folders apply to you, or you don't want this device
reachable from the internet, you can simply leave every file inside
them empty.
