# Cloudflare Tunnel public address

This is the public web address people will use to reach the app on
this device, for example:

    app.example.com

It needs to be a name that already exists on a domain you manage
through Cloudflare. If you're not sure what that means, it's the same
address you'd set up when creating the tunnel in the Cloudflare
dashboard.

Leave this file empty until you've decided on an address, or if you
aren't using a Cloudflare Tunnel — see this folder's `explain.md`.
