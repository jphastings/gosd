# Tailscale Funnel public name

This is the public name people will use to reach this device, as part
of an address like:

    https://device-name.your-tailnet.ts.net

Type just the name part, for example:

    device-name

Leave this file empty to use the device's own hostname (see the
`hostname` file at the top of the `config` folder) as the public name
instead.
