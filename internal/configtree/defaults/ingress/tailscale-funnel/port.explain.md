# Tailscale Funnel app port

This is the port number that the app on this device listens on — the
number Tailscale Funnel needs to know so it can hand incoming visitors
to the right place on the device.

Type just the number, for example:

    8080

If you don't know this number, check the documentation for the app
running on this device — the app's author chooses it.

Leave this file empty until you know the port number, or if you aren't
using Tailscale Funnel — see this folder's `explain.md`.
