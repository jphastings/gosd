#### `gosd docs` reads the documentation offline

`gosd docs` lists the guides built into the binary, and `gosd docs <name>` opens one in a terminal reader (or prints the raw Markdown when piped). The flag help of `gosd build`, `gosd run`, `gosd build-kernel` and `gosd build-external` is now much shorter, grouped under headings, and points at the relevant guide for each flag.
